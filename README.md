# Sales Data Analysis Dashboard

## 📊 Project Overview

This project analyzes retail sales data to identify sales trends, top-performing products, cities, and categories. The project demonstrates practical Data Analytics skills using Python, SQL, Excel, and Power BI.

## 🛠️ Tools & Technologies

- Python
- Pandas
- SQL / MySQL
- Microsoft Excel
- Power BI
- Matplotlib

## 📁 Dataset

The dataset contains 500 retail sales transactions from January to December 2025.

Key columns include:

- Order ID
- Order Date
- City
- Category
- Product
- Quantity
- Unit Price
- Discount
- Gross Sales
- Net Sales

## 🐍 Python Analysis

Python and Pandas are used for:

- Data inspection
- Missing-value checking
- KPI calculation
- Category-wise sales analysis
- City-wise sales analysis
- Monthly sales trends
- Top product analysis
- Data visualization using Matplotlib

## 🗄️ SQL Analysis

SQL queries are used to analyze:

- Total Net Sales
- Total Orders
- Total Quantity
- Average Order Value
- Category-wise sales
- City-wise sales
- Top 10 products
- Monthly sales
- City and category performance

## 📈 Power BI Dashboard

The Power BI dashboard is designed with:

- Total Sales KPI
- Total Orders KPI
- Total Quantity KPI
- Average Order Value KPI
- Monthly Sales Trend
- Category-wise Sales
- City-wise Sales
- Top Products
- Interactive filters and slicers

## 🎯 Project Objective

The main objective is to demonstrate an end-to-end Data Analytics workflow, from raw sales data to analysis and dashboard reporting.

- `POWER_BI_DASHBOARD_GUIDE.md` — Power BI dashboard guide
